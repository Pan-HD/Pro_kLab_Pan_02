TRADITIONAL BASELINE PRE-PRIMARY PROTOCOL
Generated before primary-200 evaluation.

PURPOSE
Compare manually predeclared traditional image-processing pipelines with
the GP-generated pipelines while reusing the same CUDA operator implementations
and the same STANDARD F1 evaluation path.

IMPORTANT STUDY RULE
1. Run TRAINING SANITY first (IDs 111-130).
2. Training sanity is for implementation validation only:
   tree parsing, binary output, foreground polarity, CUDA/CC_FILTER errors,
   and obvious path/configuration mistakes.
3. Do not repeatedly tune parameters to maximize training F1.
4. If a genuine implementation/polarity error is found, correct it using
   training data only and document the correction before primary-200.
5. Once definitions are accepted, freeze them.
6. Run primary-200 exactly once with the frozen definitions.
7. Never change topology/parameters after seeing IDs 211-410 performance.

PREDECLARED BASELINES
B0:
  GaussianBlur(5, 1.5) -> Threshold(9)

B1:
  GaussianBlur(5, 1.5) -> Canny(100, 200) -> Dilate(r=1; 3x3) ->
  CC_FILTER(areaTh=5, aspectRange=3)

B2:
  GaussianBlur(5, 1.5) -> Sobel-X(3) and Sobel-Y(3) -> BITWISE_OR ->
  Threshold(9) -> Dilate(r=1; 3x3) -> CC_FILTER(5, 3)

B3:
  MedianBlur(19) -> Threshold(9) -> Erode(r=1; 3x3) ->
  Dilate(r=1; 3x3) -> CC_FILTER(5, 3)

PARAMETER POLICY
The parameter values above are the current GP safe/default values.
No parameter was selected using primary-test performance.
